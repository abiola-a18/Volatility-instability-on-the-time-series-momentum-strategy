First Python Project on the Time Series Momentum strategy, The poster can be viewed on www.linkedin.com/in/abiola-abidoye. An initial prior strategy was created, you can read more at https://achaemeneans.org.uk and this project builds on the initial theory and tries to improve the Sharpe ratio of the asset whilst using the 12 month skip one time series momentum trading strategy. Initially tried to implement on GBP-USD, didn't go to plan as didn't factor in rate-hikes and other macro-economic events that cause significant noise for the model, so went for BTC-USD as it's not affected in the same way by broader macro events and Sharpe ratio on the Backtest improved by 3x. To be specific Prior Sharpe = 3.1864992176033597, New Sharpe = 9.14436612736806. The moving EWMA metric not included in the code as of now.
